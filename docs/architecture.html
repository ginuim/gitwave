GitWave Architecture

Tauri 2 桌面 Git 客户端 · Vue 3 前端 + Rust 后端 · 本地 git CLI 驱动

前端层

  • • Vue 3 Composition API + TypeScript + Tailwind CSS
  • • Splitpanes 三栏：Sidebar / Workspace|History / Diff
  • • 所有 Git 操作通过 invoke() 委托给 Rust 层
  • • AI Commit 由 WorkspacePanel 直接调用 plugin-http

后端层

  • • Tauri 2 + Rust，不嵌入 libgit2，直接 spawn git CLI
  • • AppState 持有当前 repo_path，命令无状态执行
  • • 支持 patch 级 stage/revert、subtree、二进制图片 diff
  • • get_staged_diff_for_ai 为 AI 生成结构化 diff 上下文

数据与外部依赖

  • • 本地 app_data_dir 持久化 settings / recent repos
  • • Git 仓库读写完全依赖本地 git 命令行
  • • 远程同步经 git push/pull/fetch/clone
  • • 构建：Vite → dist/ → Tauri bundle (macOS dmg / Windows nsis)
