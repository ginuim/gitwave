三栏布局

Sidebar · 工作区 · Diff，一屏掌控全局

Splitpanes 三栏可拖拽布局：左侧管理分支、远程、Stash 与 Subtree；中间切换工作区与历史视图；右侧实时渲染 unified diff，选中即看变更。

提交图

可视化分支拓扑，历史一目了然

CommitGraphView 渲染分支 lane 与 merge 节点，hover 高亮关联路径。分页加载 commit log，支持当前分支与全仓库过滤，让复杂分支历史也能快速定位。

精确 Stage

Hunk 与行级暂存，改动由你掌控

DiffPanel 支持 unified diff 渲染、hunk 级与行级 stage/revert。二进制文件可预览图片 diff。不再被迫全文件 stage，每一次提交都精确到行。

本地优先，架构透明

Tauri 2 桌面运行时 + Vue 3 前端 + Rust 后端。所有 Git 操作通过 spawn git CLI 执行，不嵌入 libgit2。AppState 持有 repo_path，命令无状态、可预测。
